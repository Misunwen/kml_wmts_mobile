# KML / KMZ / GPX + NLSC WMTS 地圖檢視器

以 **OpenLayers** 開發的純前端地圖工具，手機優先，支援載入、檢視與管理 **KML / KMZ / GPX** 地理資料，並結合 **NLSC_WMTS** 底圖。

- 線上（GitHub Pages）：https://misunwen.github.io/kml_wmts_mobile/
- 版本：`CONFIG.APP_VERSION`（顯示於面板標題列，目前 **v2026.10.02.8**）
- 版本記錄：見 [`CHANGELOG.md`](CHANGELOG.md)；交接資訊見 [`HANDOFF.md`](HANDOFF.md)

> ⚠️ 本專案使用原生 **ES Modules**，**不能直接用 `file://` 雙擊開啟**，必須透過 HTTP 伺服器或 GitHub Pages。

---

## 🚀 快速開始

### 線上下載即用
直接開 https://misunwen.github.io/kml_wmts_mobile/

### 本機執行
專案根目錄提供 `start_server.bat`（Windows）：雙擊後會自動找空埠、開伺服器並用瀏覽器開啟。

或手動：

```bat
python -m http.server 8000 --directory G:\python\WMS
```

再開 http://localhost:8000/

### 驗證版本
GitHub Pages 對所有檔案送 `Cache-Control: max-age=600`（**10 分鐘快取**）；
要確認載到最新版請用**無痕視窗**，或清「快取的圖片和檔案」。標題列會顯示 `v版本號`。

## 🎯 主要功能

### 1. NLSC WMTS 底圖
- 由 `GetCapabilities` 自動讀取圖層清單，預設 **EMAP**（臺灣通用電子地圖）。
- 下拉選單即時切換，支援 EPSG:3857。

### 2. 檔案載入
| 項目 | 說明 |
|------|------|
| 支援格式 | `.kml`、`.kmz`、`.gpx` |
| 讀取方式 | 瀏覽器 File API，**檔案不會上傳** |
| 圖層上限 | 最多 **10** 個圖層 |
| 編碼 | UTF-8 |

- **KMZ**：自動解壓縮其中的 KML。
- **多資料夾 KML/KMZ**：若 Document 底下有多個頂層 `<Folder>`，**一個資料夾 = 一個圖層**（圖層名稱＝資料夾名稱）；單一資料夾的檔案維持單層。

### 3. 圖層管理
- 顯示／隱藏、上移／下移、定位、移除。
- 每個圖層獨立**透明度**。
- 大型單色向量圖層會顯示紫色 **`WebGL`** 標籤（見下方效能）。

### 4. 點圖徵樣式
| 控制 | 範圍 |
|------|------|
| 標記大小 | **0–20 px**（0＝隱藏圓點） |
| 欄位（標籤） | 只列出圖徵真正有的屬性（如 **名稱 / 說明**），可選 **（不顯示）** |
| 字體大小 | **5–28 px** |

- 標記、字體旁有 **`−` / `+`** 按鈕，方便手機微調。

### 5. 線／多邊形樣式
| 控制 | 說明 |
|------|------|
| 線粗 | 1–10 px（含 `−` / `+`） |
| 顏色 | 色票即時套用 |
| 填滿 | 以同色半透明（約 0.35）填滿 |
| 標籤（僅多邊形） | 選欄位＋字體，屬性文字顯示於多邊形內部點；**線圖層不提供** |

- 預設樣式由 KML 推導（未調整前外觀不變）；設定會自動記錄與還原。

### 6. 面板與介面
- 標題列 `⇄` 可在**左／右**切換面板位置（存於 `localStorage`）。
- 面板可收合；**狀態列固定在標題列下方，收合時一併隱藏**。
- 手機面板以 `100dvh` 限制高度，內容可捲動；兩顆清除鈕固定在底部。

### 7. GPS 定位
- 使用瀏覽器 Geolocation API，顯示目前位置與誤差範圍，定位後縮放至 17 級。

### 8. 自動記錄與還原
- 以 IndexedDB 儲存底圖、圖層順序／顯示／透明度／樣式設定、地圖位置。
- 圖層原始文字與小筆 metadata 分開儲存，平移／縮放只更新小筆資料。
- 可關閉自動記錄或清除快取（不影響裝置上的原始檔案）。

### 9. 效能：WebGL 加速
- 條件：**沒有點圖徵**、圖徵數 **≥ 2000**、且**所有圖徵樣式一致** → 使用 `ol.layer.WebGLVector` 繪製，縮放／平移更順。
- 樣式不一致（多色）→ 自動退回 canvas，**保留原色**。
- WebGL 圖層不支援文字標籤；此類圖層不提供多邊形標籤控制。

## 🔍 縮放限制

| 項目 | 值 |
|------|----|
| 最小縮放 | 5 |
| 最大縮放 | **22** |
| 預設縮放 | 7 |
| 「定位」縮放上限 | **20** |
| NLSC 底圖圖磚層級 | **0–19** |

> 拉近超過 19 級時底圖會空白（沒有圖磚），但向量圖層仍會繪製，適合近距離分辨密集點位。

## 🛠 技術架構

| 項目 | 規格 |
|------|------|
| 核心 | OpenLayers 10.6.1（CDN，`defer`） |
| 解壓縮 | JSZip 3.10.1（CDN，`defer`） |
| 模組 | 原生 ES Modules，**無建置流程** |
| 投影 | 資料 EPSG:4326 → 地圖 EPSG:3857 |
| 儲存 | IndexedDB（自訂狀態）＋ localStorage（偏好） |
| 定位 | Geolocation API |

### 專案結構
```
index.html      應用外殼
style.css       全部樣式
js/
  config.js     CONFIG（版本、縮放、WebGL 門檻、樣式預設）
  state.js      DOM 參照 + AppState
  utils.js      工具（escape/sanitize/格式/狀態/進度）
  storage.js    IndexedDB、自動記錄（圖層文字分離）
  map.js        建立地圖 + WMTS
  parsers.js    GPX / KMZ 解析、KML 依資料夾拆分
  layers.js     圖層建立、點/線/面樣式、WebGL 判斷、CRUD
  io.js         檔案載入流程（含多圖層）
  location.js   GPS 定位
  ui.js         圖層清單渲染 + 事件綁定
  app.js        還原、初始化、啟動
OLD/            舊版 V1–V4 與遠端舊 index/README
References/     本機 KML 資料（不上傳）
```

## 📂 KML 屬性與標籤
- 可用的標籤欄位＝圖徵實際有的屬性；常見為 `name`（名稱）、`description`（說明）。
- 內部欄位（`geometry`、`styleUrl`…）不會出現在選單。
- 多行／含 HTML 的說明在標籤中會清理並截斷，避免過長。

## ⚠️ 已知限制
- **必須用 HTTP(S)**：`file://` 無法載入 ES Modules。
- **GitHub Pages 10 分鐘快取**：更新後可能短暫看到舊版。
- **底圖上限 19 級**：20–22 級底圖空白（向量仍可顯示）。
- **大檔解析在主執行緒**：載入／重新整理還原極大 KML 時可能短暫凍結。
- **WebGL 為實驗性 API**：不支援文字標籤；多色大圖層退回 canvas，縮放時可能「消失再出現」。
- **尚未實作**：點擊圖徵彈出屬性視窗、屬性搜尋、距離／面積測量（已決定不做）。
