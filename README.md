# KML/KMZ/GPX 地圖檢視器 - 完整使用說明

---

## 📌 專案概述

這是一個基於 **OpenLayers** 開發的網頁地圖工具，專為 **行動裝置** 與 **桌面裝置** 設計，提供使用者載入、檢視與管理多種 GIS 地理資料格式（**KML**、**KMZ**、**GPX**），並結合 **國土測繪中心 WMTS** 底圖服務。

---

## 🎯 核心功能一覽

| 功能類別 | 主要功能 |
|----------|----------|
| **底圖服務** | 國土測繪中心 WMTS 底圖（自動讀取圖層清單） |
| **檔案支援** | KML、KMZ（自動解壓縮）、GPX |
| **圖層管理** | 顯示/隱藏、排序、透明度、移除、定位 |
| **點標籤設定** | 標記大小、標籤欄位、文字大小（KML/KMZ） |
| **GPX 線條設定** | 線條粗細調整（航跡/航線） |
| **GPS 定位** | 顯示目前位置與誤差範圍 |
| **自動記錄** | 儲存所有設定與圖層資料（IndexedDB） |
| **安全防護** | XSS 過濾、檔案驗證 |

## 📂 支援的檔案格式

| 格式 | 副檔名 | 圖示 | 說明 |
|------|--------|------|------|
| **KML** | `.kml` | 📄 | Keyhole Markup Language，Google Earth 標準格式 |
| **KMZ** | `.kmz` | 📦 | 壓縮的 KML（ZIP 格式），瀏覽器自動解壓縮 |
| **GPX** | `.gpx` | 📍 | GPS Exchange Format，GPS 裝置與運動手錶常用 |

### 各格式支援內容

| 格式 | 支援內容 | 顯示方式 |
|------|----------|----------|
| **KML** | 點（Point）、線（LineString）、面（Polygon） | 點：紅色圓點+標籤<br>線/面：保留 KML 原始樣式 |
| **KMZ** | 內部 KML 檔案（自動解壓縮） | 與 KML 相同 |
| **GPX** | 航點（wpt）、航跡（trk）、航線（rte） | 航點：紅色圓點<br>航跡：藍色線條<br>航線：綠色線條 |

- 等（依國土測繪中心提供）

## 📱 圖層管理功能

每個載入的圖層都具備以下控制：

| 控制項 | 說明 |
|--------|------|
| **☑ 顯示/隱藏** | 點擊 checkbox 切換圖層可見性 |
| **圖層名稱** | 點擊展開/收合進階設定 |
| **↑ 上移** | 將圖層往上移動（疊加順序） |
| **↓ 下移** | 將圖層往下移動（疊加順序） |
| **定位** | 自動縮放至該圖層的資料範圍 |
| **✕ 移除** | 從地圖中移除該圖層 |

### 圖層順序說明
- 清單中 **最上方** 的圖層 = 地圖上 **最上層**（蓋住其他圖層）
- 清單中 **最下方** 的圖層 = 地圖上 **最底層**
- 使用 ↑ / ↓ 按鈕調整順序

## ⚙️ 進階圖層設定

點擊圖層名稱可展開/收合進階設定區：

### 通用設定（所有圖層）

| 控制項 | 說明 | 範圍 | 預設值 |
|--------|------|------|--------|
| **透明度** | 調整圖層透明度 | 0% ~ 100% | 100% |

### KML / KMZ 點設定（僅點圖徵）

| 控制項 | 說明 | 範圍 | 預設值 |
|--------|------|------|--------|
| **標記** | 紅色圓點的半徑大小 | 3 ~ 20 px | 7 px |
| **欄位** | 選擇顯示的屬性欄位 | 自動偵測 | name |
| **字體** | 標籤文字大小 | 8 ~ 28 px | 13 px |

### GPX 線條設定

| 控制項 | 說明 | 範圍 | 預設值 |
|--------|------|------|--------|
| **線寬** | 控制航跡/航線的線條寬度 | 1 ~ 12 px | 3 px |

**GPX 線條顏色**：
- 🟦 航跡（Track）：藍色
- 🟩 航線（Route）：綠色

| 項目 | 說明 |

## 💾 自動記錄與狀態還原

| 項目 | 說明 |
|------|------|
| 儲存媒介 | IndexedDB（瀏覽器本地資料庫） |
| 啟用方式 | 預設啟用，可透過 checkbox 開關 |
| 儲存內容 | 底圖、所有圖層、順序、透明度、點設定、線寬、地圖位置 |
| 還原機制 | 重新整理頁面後自動還原 |
| 清除方式 | 點擊「清除快取資料」按鈕 |

### 儲存的資料內容
```javascript
{
  wmtsLayer: "EMAP",              // 目前底圖
  view: {
    center: [x, y],               // 地圖中心
    zoom: 15,                     // 縮放等級
    rotation: 0                   // 旋轉角度
  },
  kmlLayers: [
    {
      name: "景點.kml",
      format: "kml",              // 或 "kmz" / "gpx"
      text: "<kml>...</kml>",     // 完整檔案內容
      visible: true,
      opacity: 0.8,
      pointRadius: 7,             // KML/KMZ 點標記大小
      pointLabelField: "name",    // 標籤欄位
      pointLabelSize: 14,         // 標籤文字大小
      gpxLineWidth: 3             // GPX 線條寬度
    }
  ]
}
```

## 🔒 安全性設計

| 防護項目 | 說明 |
|----------|------|
| **XSS 防護** | 自動移除 `<script>` 標籤 |
| **事件屬性移除** | 移除 `on*` 事件處理器（如 onclick） |
| **偽協議移除** | 移除 `javascript:` 偽協議 |

| **本地處理** | 所有檔案僅在瀏覽器端處理，**不上傳任何伺服器** |

## 🚀 快速開始

### 步驟 1：開啟網頁
在瀏覽器中開啟 HTML 檔案（可離線使用，但 WMTS 底圖需要網路）

### 步驟 2：等待底圖載入
自動讀取 WMTS 圖層清單，預設載入 EMAP 電子地圖

### 步驟 3：載入 GIS 檔案
點擊「載入 GIS 檔案」，選擇 KML / KMZ / GPX 檔案（可複選）

### 步驟 4：檢視與管理圖層
- 自動縮放至圖層範圍
- 調整顯示順序、透明度
- 展開設定調整點標記/標籤/線寬

### 步驟 5：定位（可選）
點擊「📍 定位到我的位置」顯示目前位置

### 步驟 6：自動記錄
所有設定自動儲存，下次開啟自動還原

## ❓ 常見問題

### Q1：為什麼 KMZ 檔案無法讀取？
**A**：請確認：
1. 網路連線正常（JSZip 需從 CDN 載入）
2. KMZ 檔案內部包含 `.kml` 檔案
3. 檔案未損壞

### Q2：GPX 的航點可以調整樣式嗎？
**A**：GPX 航點目前套用與 KML 點相同的樣式（紅色圓點），但 KML 的點設定（標記大小、欄位、字體）**僅適用於 KML/KMZ 格式**。GPX 航點暫不支援獨立調整。

### Q3：可以同時載入多少個圖層？
**A**：最多 10 個圖層。這是為了確保行動裝置的效能與操作流暢度。

### Q4：自動記錄的資料儲存在哪裡？
**A**：儲存在瀏覽器的 IndexedDB 中（位於裝置本地），不會上傳任何伺服器。

### Q5：清除快取會刪除原始檔案嗎？
**A**：不會。清除快取只會刪除 IndexedDB 中的記錄資料，原始 KML/KMZ/GPX 檔案仍保留在您的裝置中。

### Q6：支援哪些瀏覽器？
**A**：建議使用最新版的：
- Google Chrome（行動版/桌面版）
- Apple Safari（iOS/macOS）
- Microsoft Edge
- Mozilla Firefox

### Q7：需要網路連線嗎？
**A**：
- **需要**：載入 WMTS 底圖
- **不需要**：載入與檢視 KML/KMZ/GPX 檔案（離線可用）
