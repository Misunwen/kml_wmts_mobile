

# KML + WMTS 地圖檢視器

## 📌 專案概述

這是一個基於 **OpenLayers** 開發的網頁地圖工具，專門設計用於 **行動裝置** 與 **桌面裝置**，提供使用者載入、檢視與管理 **KML** 地理資料檔案，並結合 **NLSC WMTS** 底圖服務。

---

## 🎯 主要功能

### 1. NLSC WMTS 底圖

| 項目 | 說明 |
|------|------|
| 資料來源 | NLSC WMTS 服務（https://wmts.nlsc.gov.tw/wmts） |
| 圖層數量 | 自動讀取 GetCapabilities 清單，通常包含 10+ 個圖層 |
| 預設圖層 | EMAP（臺灣通用電子地圖） |
| 切換方式 | 下拉選單即時切換 |
| 特色 | 支援 EPSG:3857（Google Maps 投影），與 OpenLayers 完美整合 |

**可用的底圖範例**：
- EMAP（通用電子地圖）
- 衛星影像
- 地形圖
- 行政區界圖
- 等

---

### 2. KML 檔案載入與管理

| 項目 | 說明 |
|------|------|
| 支援格式 | `.kml` 檔案（XML 格式） |
| 載入方式 | 瀏覽器 File API，**不會上傳至任何伺服器** |
| 同時載入上限 | 最多 10 個 KML 圖層 |
| 檔案大小限制 | 無限制（但過大可能影響效能） |
| 編碼支援 | UTF-8 |

**支援的 KML 圖徵類型**：
- ✅ 點（Point / MultiPoint）
- ✅ 線（LineString / MultiLineString）
- ✅ 面（Polygon / MultiPolygon）
- ✅ 多幾何（MultiGeometry）

---

### 3. 圖層管理功能

每個載入的 KML 圖層都具備以下控制：

| 功能 | 說明 |
|------|------|
| 顯示/隱藏 | 點擊 checkbox 切換圖層可見性 |
| 圖層排序 | ↑ 上移 / ↓ 下移，調整圖層疊加順序 |
| 縮放至圖層 | 自動縮放至該圖層的資料範圍 |
| 移除圖層 | 從地圖中移除該 KML 圖層 |
| 透明度調整 | 滑桿控制 0% ~ 100%（每個圖層獨立） |

---

### 4. 點圖徵標籤設定

針對 KML 中的 **點（Point）** 圖徵，提供以下自訂選項：

| 項目 | 說明 |
|------|------|
| 標籤欄位 | 下拉選單選擇要顯示的屬性欄位（name / description / title / 自訂） |
| 文字大小 | 數字輸入框調整（8 ~ 28px） |
| 自動偵測 | 自動讀取 KML 內所有可用欄位 |
| 即時更新 | 變更設定後立即反映在地圖上 |

**點標籤樣式**：
- 紅色圓點標記（rgba(235,40,40)）
- 白色外框文字，清晰易讀
- 自動避免標籤重疊（declutter）

---

### 5. GPS 定位功能

| 項目 | 說明 |
|------|------|
| 定位方式 | 瀏覽器 Geolocation API |
| 精確度 | 啟用高精確度模式（enableHighAccuracy: true） |
| 視覺回饋 | 藍色圓點標記目前位置 + 半透明誤差範圍圓圈 |
| 自動縮放 | 定位完成後自動縮放至 17 級 |
| 超時設定 | 15 秒定位超時 |

**定位狀態回饋**：
- 定位中：按鈕顯示「正在定位...」
- 定位完成：顯示經緯度與誤差範圍
- 定位失敗：顯示具體錯誤原因（權限拒絕 / 訊號不良 / 逾時）

---

### 6. 自動記錄與狀態還原

| 項目 | 說明 |
|------|------|
| 儲存媒介 | IndexedDB（瀏覽器本地資料庫） |
| 儲存內容 | 底圖選擇、KML 資料、圖層順序、顯示狀態、透明度、點標籤設定、地圖位置 |
| 啟用開關 | 可隨時開啟/關閉自動記錄 |
| 還原機制 | 頁面重新整理後自動還原 |
| 容量限制 | 受瀏覽器 IndexedDB 配額限制（通常 > 50MB） |

**儲存的資料項目**：
```javascript
{
  wmtsLayer: "EMAP",          // 目前選用的底圖
  view: {
    center: [x, y],           // 地圖中心座標
    zoom: 15,                 // 縮放等級
    rotation: 0               // 旋轉角度
  },
  kmlLayers: [
    {
      name: "景點.kml",
      text: "<kml>...</kml>", // 完整 KML 內容
      visible: true,
      opacity: 0.8,
      pointLabelField: "name",
      pointLabelSize: 14
    }
  ]
}
```

---

### 7. 載入進度回饋

| 項目 | 說明 |
|------|------|
| 進度條 | 顯示目前載入進度（0% ~ 100%） |
| 檔案名稱 | 即時顯示正在處理的 KML 檔案名稱 |
| 數量顯示 | 顯示「目前/總數」進度 |
| 自動消失 | 載入完成後自動隱藏 |

---

### 8. 安全性防護

| 項目 | 說明 |
|------|------|
| XSS 防護 | 自動移除 KML 中的 `<script>` 標籤 |
| 事件屬性移除 | 移除 `on*` 事件處理器 |
| 偽協議移除 | 移除 `javascript:` 偽協議 |
| 檔案驗證 | 檢查副檔名與 MIME Type |
| 內容跳脫 | 狀態訊息使用 `textContent` 防止注入 |

| 項目 | 規格 |
|------|------|

## 🔒 隱私與安全

| 項目 | 說明 |
|------|------|
| 資料不上傳 | KML 檔案僅在瀏覽器端處理，**不會上傳至任何伺服器** |

## ⚠️ 使用限制

| 項目 | 說明 |
|------|------|
| KML 圖層上限 | 最多 10 個（可調整） |
| 單一 KML 大小 | 無強制限制，但過大可能影響效能 |
| 瀏覽器相容性 | 建議使用 Chrome / Edge / Safari 最新版 |

## 🚀 快速開始

### 使用步驟

1. **開啟網頁**：在瀏覽器中開啟此 HTML 檔案
2. **等待底圖載入**：自動讀取 WMTS 圖層清單
3. **載入 KML**：點擊「載入本機 KML」選擇檔案（可多選）
4. **檢視地圖**：自動縮放至 KML 範圍
5. **調整圖層**：
   - 顯示/隱藏、排序、透明度
   - 點圖徵的標籤欄位與大小
6. **定位**：點擊「📍 定位到我的位置」
7. **自動記錄**：所有設定會自動儲存，下次開啟自動還原

### 快速鍵與手勢

| 操作 | 說明 |
|------|------|
| 點擊標題列 | 收合/展開控制面板 |
| 點擊圖層名稱 | 展開/收合該圖層的進階設定 |
| 滑桿拖曳 | 調整透明度 |
| 數字輸入 | 調整標籤文字大小 |
